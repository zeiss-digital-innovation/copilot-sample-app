## Exercises
### Task 1
Delete `.github/copilot-instructions.md` and generate a new one (to simulate working in your real project)

### Task 2
Using Plan Mode, plan a feature. Then implement it.

### Task 3
Create a Custom Instruction (`.github/instructions/`)
Example: `frontend.instruction.md` for frontend specific topics

### Task 4
Create a Custom Agent, e.g for Security, Code Review, Testing, ... or download from awesome-copilot repo

### Task 5
Install an MCP Server and use it, e.g. playwright-mcp
Example usage: "Open the app in a browser and take a screenshot"
Bonus: Configure the MCP Server in a Custom Agent
 
Example ADO: "List all my projects in Azure DevOps"
